# Neon Viper - Cyberpunk Snake Game

A sleek, neon-themed Snake game with a cyberpunk aesthetic. Built with vanilla HTML, CSS, and JavaScript.

## Play Online

🎮 **[Play Neon Viper](https://alana206.github.io/snake/)**

## Features

- 🎯 Classic snake gameplay with modern neon styling
- 📱 Mobile-friendly with touch controls
- ⌨️ Keyboard support (Arrow keys or WASD)
- 🎨 Cyberpunk neon aesthetics
- 🔊 Smooth gameplay at 150ms intervals

## Controls

- **Arrow Keys** or **WASD** - Move the snake
- **Enter** - Start/Restart the game
- **Touch** - Swipe on mobile devices

## Getting Started

1. Clone the repository
2. Open `index.html` in a web browser
3. Or visit the live version: https://alana206.github.io/snake/

## Files

- `index.html` - Main game structure
- `style.css` - Neon styling and layout
- `script.js` - Game logic and input handling

## Technologies

- HTML5 Canvas
- Vanilla JavaScript
- Tailwind CSS
- Custom CSS for neon effects
